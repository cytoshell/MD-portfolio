
# Portfolio Website

This is a personal portfolio to showcase my programming projects & contributions, projects I have planned, and more information about me. It is currently in development, but I hope to have it completed soon. Please check back later for updates and new content.

My goal is to spend about an hour each day working on this website, so I can make steady progress, have it completed in a reasonable amount of time, and not contribute to my burnout. This would be the first time I've built a website from scratch but I hope to learn a lot and make a website that I can use for the future. I want to make this entirely without the assistance of any website builders, templates, or ai in order to learn as much as I can.
